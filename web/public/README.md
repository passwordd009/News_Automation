# Static assets

## hestia-logo.png — required

Save the Project Hestia mark (the Greek key ring around the branching tree)
here as `hestia-logo.png`.

A square PNG with a transparent background is ideal, 512×512 or larger. The
mark is black line art and is inverted automatically in dark mode, so a
transparent background matters more than the exact size.

Until the file exists, `HestiaLogo` falls back to a plain drawn meander ring —
enough to keep the layout intact, but deliberately not an imitation of the real
artwork.
